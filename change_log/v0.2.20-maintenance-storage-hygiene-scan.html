v0.2.20 Maintenance Storage Hygiene Scan

Adds a read-only scan for accumulated WSA/Hermes artifacts so high-volume users can see cleanup pressure before taking action.

maintenance scan storage hygiene callbacks archives no cleanup execution

What Changed

wsa artifact maintenance-scan summarizes managed artifact roots by file count and bytes.

  • Reports and report mailboxes
  • Hermes task/callback queues and archives
  • Session logs and exports
  • Orchestrator runs, meetings, and scenes

Recommended Actions

The scan calls out pending queues, callback residue, source-map-less exports, and large archive roots as operator review items.

Write Mode

--write stores a scan JSON under manager/maintenance_plans/. It does not archive or delete anything.

Operational Flow

1. Scan Count managed roots and identify high-pressure areas.
2. Diagnose Use source-map status and queue counts to rank cleanup risks.
3. Plan Write a scan before pruning, archiving, or uninstalling.
4. Decide Hermes/user chooses cleanup policy outside this read-only scan.
