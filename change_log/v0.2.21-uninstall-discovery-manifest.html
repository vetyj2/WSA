v0.2.21 Uninstall Discovery Manifest

Adds read-only discovery for WSA-adjacent paths outside the managed workspace architecture before any delete-capable uninstall step exists.

uninstall discovery external scan roots classification exclude roots no deletion

What Changed

wsa artifact uninstall-discover scans explicit roots for WSA-adjacent files and directories.

  • Source checkout detection
  • Workspace DB detection
  • External artifact and artifact collection detection
  • Backup preserve and runtime-owned review classification

Safety Boundary

Discovery is not a delete manifest. It records evidence, confidence, and recommended action, then requires user review before any future apply step.

External Backups

--exclude-root marks backup roots as preserve-only and prevents traversal into them.

Runtime Follow-Up

After any future uninstall apply, operators should run Hermes doctor or equivalent runtime diagnostics to catch stale shortcuts, overlays, callback routes, and runtime-owned WSA memory.

Operational Flow

1. Discover Scan explicit roots and classify candidates with evidence.
2. Review User/Hermes reviews source, workspace, backup, runtime-owned, and unknown groups.
3. Plan Only exact approved paths should move into a later uninstall plan.
4. Apply Later Actual deletion remains a future explicit-approval lifecycle.
