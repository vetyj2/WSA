Scene Bridge Prep

This patch makes scene prep usable through a compact Hermes bridge command while preserving WSA's public-template boundary and existing user databases.

Live Flow

wsa scene start

Creates a bounded scene_generation run in bridge mode.

Hook Packet

Returns the next actor/subsession prompt and terminal command shape.

Hermes Runtime

Calls actors or subagents and writes callback JSON.

Quality Gate

Accepted outputs only; retry limit stops bad loops.

Prep Package

Returns scene prep, risk flags, and approval choices without canon mutation.

Module Changes

cli.py

Adds wsa scene start and wsa scene prep as short routes for Hermes bridge scene prep.

autonomous_orchestrator.py

Records scene_filter_contract and builds wsa.scene.prep_package.v1.

orchestrator_bridge.py

Preserves scene-specific callback fields and stops repeated bad callbacks after a bounded retry limit.

Template Neutrality

Removes overly specific world examples from public docs/tests and keeps personal world direction out of the template.
