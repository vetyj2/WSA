v0.2.19 Uninstall Dry-Run Lifecycle

Adds an uninstall ownership plan that shows what to preserve, archive, and review before any cleanup is considered.

uninstall plan dry-run preserve boundary archive first no deletion

What Changed

wsa artifact uninstall-plan previews uninstall ownership boundaries without deleting or moving files.

  • Preserve-by-default: control DB, world DBs, startup profiles, local Hermes overlay.
  • Archive candidates: reports, task/callback archives, session logs, run JSON, scenes, meetings.
  • Delete-after-archive candidates: runtime residue and derived exports only after review.

Write Mode

--write stores a plan JSON under manager/uninstall_plans/. It does not execute the plan.

Source-Map Gate

Invalid source maps or source-map-less exports become review blockers before any destructive cleanup can be trusted.

Operational Flow

1. Diagnose Run doctor and artifact diagnostics first.
2. Plan Generate or write a dry-run uninstall plan.
3. Backup Create an operator backup outside the workspace.
4. Decide User/runtime chooses archive, migrate, ignore, or later delete actions.
