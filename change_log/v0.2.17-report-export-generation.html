v0.2.17 Report Export Generation

Generates on-demand TXT/HTML artifacts from orchestrator run logs while keeping source logs and world databases separate.

report export TXT/HTML source map session log zone on-demand

What Changed

wsa report export can render the three recommended report artifact shapes from an orchestrator run.

  • human_session_minutes
  • draft_output
  • round_orchestration_report

Write Policy

Preview is read-only. --write stores the export under worlds/{world_id}/artifacts/session_logs/ with an artifact_source_map.json manifest.

Runtime Boundary

Exports are derived artifacts. They do not send chat, approve canon, mutate facts, or claim real Hermes execution beyond the source run metadata.

Operational Flow

1. Run Meetup or Scene creates an orchestrator run JSON.
2. Export Operator requests a specific report shape and format.
3. Trace Written exports point back to the run JSON through a manifest.
4. Deliver Hermes or another runtime decides whether to send or attach the artifact.
