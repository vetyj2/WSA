v0.2.12 Scene Evidence Ledgers

Adds explicit fact-audit evidence and writing-room line-build ledger contracts so Scene reports can prove what actors actually checked, proposed, rejected, retried, or adopted.

fact-audit evidence line-build ledger callback fields scene prep claim discipline
  • wsa.scene.fact_audit_evidence.v1 records source refs, lookup queries, checked tables/reports, conflicts, and deferred claims.
  • wsa.scene.line_build_ledger.v1 records candidate text, PASS/FAIL/HOLD/RETRY decisions, rollback reasons, and adopted markers.
  • Mode contracts are embedded into scene hook packets for Hermes or other external actor runtimes.
  • Reports stay conservative when evidence or ledger entries are absent.

v0.2.11 Scene Mode Disclosure

Adds scene mode disclosure and actor contribution accounting so Scene Start reports distinguish fact-audit synthesis from writing-room line-build work.

scene mode actor accounting fact audit line-build evidence honest reporting
  • scene start --generation-mode accepts auto, fact-audit-synthesis, and writing-room-line-build.
  • Run artifacts record requested/resolved mode, resolution source, confidence, what actors did, and what was not performed.
  • Actor contribution summaries count callbacks, rejections, rollback triggers, fact-audit evidence, co-writer evidence, and synthesizer identity.
  • The patch does not claim native line-build completion; it makes current and future modes auditable.

v0.2.10 Reporting Artifact Contract

Adds a shared reporting contract for Meetup and Scene: date-scoped session logs remain the source of truth, while minutes, draft output, and round reports are optional TXT/HTML exports.

reporting contract session logs minutes draft output on-demand export
  • wsa.reporting.artifact_contract.v1 defines recommended report shapes without forcing runtime delivery.
  • Hermes can export human_session_minutes, draft_output, and round_orchestration_report from a date-scoped session log.
  • Bridge next payloads, orchestrator contracts, command registry, and meeting transcripts expose the same policy.
  • Automatic report generation stays under user/Hermes profile customization.

v0.2.9 Local Overlay Safety

Adds local Hermes command overlay validation, merged registry preview, side-effect metadata warnings, and update preflight recommendations without expanding the official compact command surface.

local overlay merged preview update preflight side effects collision blocks
  • Runtime-specific Hermes shortcuts stay in hermes_commands.local.json instead of becoming upstream commands.
  • wsa hermes commands can write a local template, validate overlays, and preview the merged registry.

v0.2.8 Runtime Bridge Contract

Adds durable actor_state continuity, runner-agnostic bridge provenance, scheduler rationale, low-value turn warnings, and verification-pause state without making WSA execute Hermes or any other runtime.

actor_state runtime bridge scheduler provenance external execution
  • Later bridge hooks include each actor's prior stance, position, objections, unanswered questions, and continuity contract.
  • Callback acceptance updates actor_state and floor_state so Hermes can run focused follow-ups instead of restarting actors.
  • Quality gates report repetition and empty-agreement warnings for retry/deepening decisions.
  • The bridge contract is runner-agnostic: Hermes remains first target, but Codex-style local agents can consume the same hook shape later.

v0.2.7 Temporal Graph Foundation

Adds additive dynamic dimensions, time-scoped entity attributes, flexible world edges, actor knowledge records, scene selector results, prep review hooks, and graph gap reporting.

dynamic dimensions attribute spans world edges knowledge additive schema
  • Worlds can add custom labels such as location, capability, rank, or knowledge without requiring every entity to have values.

Patch Rule

For every versioned patch that changes architecture, workflow, scripts, Hermes contracts, or user-facing runtime behavior, add a new dashboard HTML under change_log/ and link it here before committing.
