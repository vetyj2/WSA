Guided Flow

ID-free

Ticket Revision

Atomic

Verification

278

일반·엄격 테스트, Ruff, mypy, build/install, public-tree, fresh-clone smoke를 통과했습니다.

World Authoring

  • Actor profile, temporal attribute, knowledge attribution, memory packet에 status/interval revision을 지원합니다.
  • 기존 기록과 새 기록을 하나의 reviewed replacement ticket으로 연결하고 provenance/lifecycle history를 보존합니다.
  • provider credential, API key, OAuth, SSH, remote execution은 계속 external runtime 경계 밖에 둡니다.
