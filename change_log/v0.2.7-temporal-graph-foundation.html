Temporal Graph Foundation

v0.2.7 adds a sparse, additive data layer for dynamic dimensions, time-scoped attributes, flexible relationships, and actor knowledge without replacing existing facts.

version v0.2.7 additive schema scene filters dynamic dimensions no canon mutation

Why This Patch Exists

Author Adds Label

A world can introduce dimensions such as capability, location, rank, knowledge, or custom values.

WSA Stores Sparse Data

Only known values are stored. Missing values are gaps, not runtime errors.

Scene Asks Conditions

Scene prep can record and resolve simple time, place, viewpoint, and attribute conditions.

Hermes Gets Gaps

Unknown dimensions or missing values become Doctor, Patrol, or Meetup follow-up targets.

Approval Boundary Holds

No fact, scene draft, or canon mutation is committed without author approval.

New Tables

TablePurpose
dimension_definitions World-local dynamic labels and value policy.
entity_attribute_spans Time-scoped entity values such as location, status, or numeric traits.
world_edges Flexible relationships across entities, facts, events, scenes, and other world objects.
knowledge_attributions What an actor knows, suspects, believes, or misunderstands at a given time.

Repository API

The new API keeps SQL centralized in WorldRepository and avoids hard enum traps.

  • define_dimension()
  • set_entity_attribute_span()
  • query_entity_attribute_spans()
  • add_world_edge() and query_world_edges()
  • add_knowledge_attribution() and query_knowledge_attributions()

Scene Contract Change

wsa scene start now includes a dynamic graph contract in scene_filter_contract.

  • Known dimensions are listed for Hermes.
  • Parsed condition keys are surfaced.
  • Unknown keys become missing_dynamic_dimensions gaps.
  • Resolvable operator filters return a bounded selector_result with matched entities.
  • Default-on prep review returns selected context bundles before the first actor hook.
  • Scene prep keeps filtering proposal-only.

Prep Review Hook

Hermes bridge runs now pause at review_prep_report before spending actor/subagent calls unless the caller opts out.

  • The report shows requirement parsing, participants, selector candidates, graph gaps, and queue limits.
  • wsa orchestrator prep-approve opens the first actor hook.
  • --no-prep-review is available for runtimes that already performed equivalent approval.

Doctor/Patrol Readiness

wsa manager diagnose can now report sparse dynamic-dimension coverage gaps.

  • Defined dimensions with missing active-entity values are flagged.
  • --fix records diagnostic logs only; it does not invent values.
  • Findings are intended to route into Patrol, Meetup, or fill planning.

Update Safety

The patch is additive-first and does not rewrite existing world data.

  • Tables are created with CREATE TABLE IF NOT EXISTS.
  • Indexes are created with CREATE INDEX IF NOT EXISTS.
  • Old world DBs are lazily supplemented when the new API is used.
  • Missing dimensions remain gaps instead of exceptions.
