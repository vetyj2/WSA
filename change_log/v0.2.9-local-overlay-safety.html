v0.2.9 Local Overlay Safety

Lets each user's Hermes runtime keep evolving local shortcuts without turning the public template into a personal command repo. WSA now validates, reports, and previews local command overlays around update and live-use boundaries.

version v0.2.9 merged preview collision blocks side-effect warnings compact command surface preserved

Patch Intent

Official WSA keeps the compact Startup, Meetup, Scene, Patrol, Doctor, and Database surface. Runtime-local aliases stay in hermes_commands.local.json. The new safety layer makes collisions and risky side effects visible before updates or live command execution resume.

1. Base RegistryGenerated from source and safe to refresh after updates.
2. Local OverlayUser/Hermes-owned shortcuts, path wrappers, and preferences.
3. ValidateBlocks base collisions and reserved namespace reuse.
4. WarnFlags mutating commands missing confirmation, side effects, or rollback guidance.
5. Merge PreviewShows the combined command surface without mutating the official registry.
6. Pre/Post UpdateHermes reports high-risk findings to the user before live use resumes.

CLI Surface

  • wsa hermes commands --write-local-template
  • wsa hermes commands --validate-local-overlay --format json
  • wsa hermes commands --merged --format json
  • --local-overlay can inspect a custom overlay path.

Update Preflight

  • Local overlay collision now returns actionable block details.
  • Mutating local commands with weak metadata return warnings.
  • Recommended actions tell Hermes what to brief before and after updates.
  • Generated base registries remain refreshable; local overlays remain protected.

What Stayed Out

  • No personal live-workspace command names were officialized.
  • No Telegram-specific natural-language routing was added to core.
  • No extra top-level status/preflight shortcuts were created.
  • No Hermes execution ownership moved into WSA.

Risk Rules

Finding Status Hermes/User Action
Local command or alias collides with base registry block Rename the local shortcut before update or live use.
Local shortcut uses reserved /wsa_ or /filltherest namespace block Move it to a runtime-local namespace.
Mutating local command lacks confirmation or rollback metadata warn Brief the user and add side-effect metadata when possible.
Overlay absent or valid read-only overlay pass No action required.
