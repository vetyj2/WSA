v0.2.18 Artifact Source-Map Diagnostics

Adds read-only diagnostics for export manifests and unmanaged export residue before uninstall or maintenance tooling grows.

source-map diagnostics read-only orphan exports doctor summary warn before cleanup

What Changed

wsa artifact diagnose now scans managed report export directories and artifact_source_map.json manifests.

  • Invalid JSON/schema becomes a blocking finding.
  • Missing source maps for export files become warnings.
  • Manifest entries pointing to missing files become warnings.

Doctor Summary

wsa doctor reports source-map status and orphan export count without dumping the full diagnostic payload.

Safety

The diagnostic never deletes, moves, or normalizes files. It only prepares the workspace for later uninstall and storage hygiene decisions.

Operational Flow

1. Export Report exports write a source-map manifest.
2. Diagnose Source maps and orphan exports are checked read-only.
3. Report Hermes can brief the user about broken traceability.
4. Cleanup Later Uninstall and maintenance can rely on the diagnostic instead of guessing.
