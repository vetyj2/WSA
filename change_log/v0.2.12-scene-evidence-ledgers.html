v0.2.12 Scene Evidence Ledgers

Fact-audit and writing-room scene modes now have explicit evidence contracts, so reports can distinguish real checks from guardrail synthesis.

fact-audit evidence line-build ledger callback contract scene prep package honest mode claims

Why This Patch Exists

v0.2.11 disclosed the requested scene mode. v0.2.12 adds the minimum evidence required to support that disclosure.

  • fact_audit_synthesis needs source refs, lookup notes, checked tables/reports, conflicts, and deferred claims.
  • writing_room_line_build needs ledger entries for proposed lines or beats, validator decisions, rollback reasons, and adopted markers.
  • Without those fields, the report stays conservative: guardrail/synthesis, not deep audit or consensus drafting.

New Contracts

  • wsa.scene.fact_audit_evidence.v1
  • wsa.scene.line_build_ledger.v1
  • Mode contracts are included in scene prompt packets.
  • Actor contribution summaries include evidence and ledger counts.

Runtime Boundary

WSA still does not execute Hermes actors directly. The external runtime fills callback fields; WSA validates, records, summarizes, and reports.

  • Callback fields remain bounded and sanitized.
  • Canon mutation remains forbidden.
  • Reports only upgrade claims when evidence exists.

Scene Flow

1. Scene Start Hermes/user selects auto, fact-audit synthesis, or writing-room line-build.
2. Hook Packet WSA includes the relevant mode contract and expected callback shape.
3. Runtime Callback Hermes reports source refs, checked records, candidate lines, validation decisions, or rollback reasons.
4. WSA Report Scene prep package carries evidence summary and line-build ledger for author review.

Fact-Audit Evidence

  • source_refs
  • fact_lookup_queries
  • checked_tables and checked_reports
  • proposal_or_quarantine_refs
  • conflicts_found, deferred_claims, unchecked_claims

Line-Build Ledger

  • beat_id, line_id, candidate_text
  • line_candidates, accepted_lines, accepted_beats
  • validation_decision: PASS, FAIL, HOLD, RETRY
  • rollback_reason, retry_count, adopted marker

Implementation Footprint

  • scene_modes.py owns contracts and summaries.
  • orchestrator_bridge.py accepts evidence/ledger callback fields.
  • autonomous_orchestrator.py records empty summaries for local simulation and populated summaries for callbacks.
  • reporting_contract.py declares the reporting criteria.
