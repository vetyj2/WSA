Round Boundary Progress Policy

This patch adds an opt-in reporting contract for long meetup and scene-prep runs. WSA records the policy; Hermes decides whether to deliver progress messages to the user.

Reporting Rule

WSA Run

Run state exposes progress_report_policy.

Opt In

Disabled by default. Hermes/user runtime chooses delivery.

Boundary

Report only at explicit round or checkpoint boundaries.

Label

Include current and max round, or round plus turn if needed.

Final

Final report must include stop reason and side-effect status.

Contract Surface

orchestrator_contract.py

Adds wsa.orchestrator.progress_report_policy.v1 with opt-in delivery, round templates, allowed exceptions, and final report fields.

autonomous_orchestrator.py

Stores the policy in plans and run payloads for simulated and Hermes bridge modes.

orchestrator_bridge.py

Returns the policy from orchestrator next so Hermes can apply it while driving callbacks.

Registry

The Hermes command registry exposes the same policy under the orchestrator runtime contract.
